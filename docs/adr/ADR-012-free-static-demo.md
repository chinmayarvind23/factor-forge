# Free static research evidence deployment

Accepted under the user's instruction to deploy on Hugging Face's free plan and
provide AWS setup instructions only.

The public Space packages actual executions of two original synthetic monthly
scenarios. The Python builder verifies the reachable artifact closure; the browser
checks each result's bytes before rendering its portfolio observations and decisions.
Private research bundles are never build inputs.

Static hosting satisfies the free-account constraint without changing API identity,
PostgreSQL durability or Docker sandbox boundaries. The tradeoff is that new model
and research execution runs locally using the documented command. A Docker Space
could host Python but currently requires a paid plan to create.

AWS implementation, EKS workers and optional distributed services are excluded from
the current delivery path. Their architecture remains documented as an extension.
