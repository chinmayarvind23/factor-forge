# HAC mean-return diagnostic

`validation/hac.py` estimates the covariance of an intercept-only sample mean using
Bartlett Newey-West weights. The caller supplies an ordered, equally spaced series,
an explicit lag count and either no correction or the intercept-only factor n/(n-1).
Missing observations must not be dropped to create apparently consecutive periods.
The diagnostic accepts 2–10,000 observations and at most 120 lags, with lag < n.

With centered observations u, it computes
`S = sum(u²) + 2 * sum_l((1-l/(L+1)) * sum_t(u_t*u_(t-l)))`.
The covariance of the mean is `S/n²`, multiplied by the selected correction.
Residual products and accumulation use exact fractions. Conversion, square root
and the mean/standard-error ratio use the existing fifty-digit decimal context.
The retained result includes every input and policy. A constant series keeps zero
variance and standard error, with `ZERO_HAC_VARIANCE` for the unavailable t-statistic.
No p-value, annualization, model-selection adjustment or promotion threshold is inferred.

The original hand example `[1,2,3,4]`, lag one, no correction produces variance
25/64, standard error 5/8 and t-statistic 4. Fourteen additional reference cases
were generated by statsmodels 0.14.6 using intercept-only OLS and `cov_hac`, covering
two original vectors, multiple lag windows and both correction choices. The
regression tolerance is relative 1e-12 and absolute 1e-15 for binary64 comparison.
The reference library is used in an isolated environment, not added to application dependencies.

Regenerate references with:

```powershell
uv run --no-project --with statsmodels==0.14.6 python infra/validation/statsmodels_hac_reference.py data/validation/hac-reference.json
```

The request requires explicit choices rather than inheriting library defaults.
The [statsmodels covariance documentation](https://www.statsmodels.org/stable/generated/statsmodels.stats.sandwich_covariance.cov_hac.html)
describes its Bartlett weighting, small-sample correction and equally spaced series assumption.
Saved result and fold adapters must establish series provenance and cadence before
using this diagnostic in research validation. HAC assumptions and sample adequacy
remain part of the research assessment.
