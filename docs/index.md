# FactorForge documentation

FactorForge connects research ideas, source material, executable strategy definitions
and retained decisions in a resumable workflow.

- [Research operator](research.md): prepare, execute, resume and inspect work.
- [Sources and data](data.md): admit literature and market inputs.
- [Architecture](architecture.md): component boundaries and design choices.
- [Deployment](deployment.md): local services, static hosting and AWS configuration.
- [Security](security.md): permissions, data handling and sandbox operation.
- [Development](development.md): tests, builds and repository structure.
- [Demo](demo.md): watch the recorded journey and open the interactive application.
